Buttons:
Move Left One Digit                     Toggle Mode (CC/CV/CR/CP)
Move Right One Digit                    Toggle HV/LV mode
Increase Digit                          Reserved for future use
Decrease Digit                          Load On/Off


Buttons are connected on pins PC6 through PC12 and PD0, which will be configured to use EXTI0,6..12.

The ISR will include a debouncing algorithm that does not allow the ISR to be called more than once per every 100 ms (use SysTick counter?)

Buttons being held down will be supported through an external timer which calls the state machine to check button states at regular intervals.
